The one rule

Nothing is hand-drawn.

A design folder that is drawn by hand rots the first time a colour changes. Here every artifact is the output of a small script you can re-run — so the mockup, the icon, the landing page and the App Store screenshots can never disagree with each other.

Ten constraint files

Each decision has one owner.

The skill ships ten short concept files. None of them is a chapter to paste onto the board — each owns one slice of the tokens, or one artifact, and says which files it writes.

Why it holds up

Three rules it will not break.

Aa

Semantic tokens only

UI code references names like textSecondary, never a hex. Raw values live in one file and the generators, so a palette change is one edit.

4.5

The gate is a hard stop

Every semantic pair is checked in both directions, and the minimum is never lowered to make a palette pass. If it fails, the tokens change.

↻

Purity by construction

If iOS and Android ever need separate hand edits, the generator is missing a rule. The same script emits both, or the script is wrong.

Questions

Before you ask

Is this a Figma replacement?

No. Figma is where you explore with a team. This is where a design becomes buildable: tokens, real CSS, platform assets and a gate that fails CI. It's the folder you keep after the exploration is done.

Do I need design experience?

No, but you do need to answer the interview. The skill asks about the promise, the user, the moment of use and what the product must never do. If you skip that, you get a generic design — which is the failure mode this exists to avoid.

Does it work for iOS and Android?

Yes, natively. Icons and illustrations are emitted for both from one source: opaque full-bleed .appiconsets for iOS, and 108dp adaptive layers with a real <monochrome> drawable for Android. Tokens are mirrored into Kotlin and Swift.

What if I already have a brand?

Bring it to the interview — logo, licensed typefaces, brand hexes. Phase 1 is explicitly about inventorying what's reusable before inventing anything. It won't replace a mark you already ship.

Why does it insist on a contrast checker?

Because “accessible enough” is an opinion until it's a failing build. Every semantic pair is tested in both directions, and the minimum is never lowered to make a palette pass. It's the only automated gate in the folder, so it has to be real.

Where do the screenshots come from?

Headless Chrome. A generator writes the artboard HTML at the exact required size, adds the right platform chrome, and screenshots it. Nothing is exported by hand, so a token change updates every listing on the next run.

Which agents can run it?

Any agent that can read files and run Node: Claude Code, Codex, OpenCode, Cursor, Windsurf. The skill is just markdown plus three small scripts — there is no plugin API to depend on.
